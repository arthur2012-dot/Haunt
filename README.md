# Haunt Firmware

**Haunt** is an **independent system** for the ESP32 Cheap Yellow Display (CYD).

It is only **compatible** with Bruce Firmware (can reuse boot and asset ideas), but it is **not** an extension or theme of Bruce. The goal is a standalone experience.

> Status: **Beta**  
> Built for **Batista**

---

## Features

- Custom boot animation (Gengar + progress bar)
- Clean modern UI screen designs
- Icon set + status icons
- Lightweight and optimized for ESP32
