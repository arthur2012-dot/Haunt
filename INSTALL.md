# How to install Haunt Theme

## Quick Install

1. Download the file **Haunt_Theme_Complete.zip** from this repository (or from the releases).
2. Extract it.
3. Copy **all files** from the `haunt_theme` folder to the **root** of your SD card (or LittleFS).
4. On the CYD device:
   - Go to **Config → UI Theme**
   - Select **Haunt.json**
5. Restart the device. The new boot animation and icons should load.

## Files included

- `boot.gif` → Official Haunt boot screen
- `Haunt.json` → Theme configuration
- All menu icons (wifi, ble, rf, rfid, etc.)
- Status icons (success, error, warning, info)
- Background

## Notes

- Optimized for ESP32-2432S028 (CYD 320x240)
- Compatible with Bruce Firmware
- Keep the assets small for best performance
