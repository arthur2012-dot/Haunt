# Haunt UI Screens

## Available Screens

| Screen       | Description                     |
|--------------|---------------------------------|
| Home         | Main launcher                   |
| Clock        | Time + uptime + memory          |
| WiFi         | Network list with signal        |
| Bluetooth    | Paired / available devices      |
| RF Scan      | Frequency scanner + signal bars |
| Storage      | SD card usage + folders         |
| Logs         | System event log                |
| Files        | File browser                    |
| Config       | Settings                        |
| System       | Battery, RAM, status            |
| About        | Version + Gengar                |

All screens are designed for 320×240 (CYD).
